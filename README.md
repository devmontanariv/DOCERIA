# Espetacular Doceria

Site estático da Espetacular Doceria, construído a partir dos catálogos enviados.

## Executar localmente

Abra `index.html` no navegador ou use qualquer servidor estático local.

A página usa imagens editoriais remotas do Unsplash para compor a direção visual. Substitua as URLs em `styles.css` pelas fotos oficiais da doceria quando estiverem disponíveis.
